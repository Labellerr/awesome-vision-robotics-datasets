# Computer Vision Datasets

| Dataset | Description | Research Paper | Tags | Link |
| :--- | :--- | :--- | :--- | :---: |
| **ImageNet** | Large visual database organized according to WordNet hierarchy (nouns). | [ImageNet: A Large-Scale Hierarchical Image Database](https://ieeexplore.ieee.org/document/5206848) | `classification` `object-detection` `general` | [Website](http://www.image-net.org/) |
| **COCO** | Large-scale object detection, segmentation, and captioning dataset. | [Microsoft COCO: Common Objects in Context](https://arxiv.org/abs/1405.0312) | `detection` `segmentation` `captioning` `keypoints` | [Website](https://cocodataset.org/) |
| **Pascal VOC** | Classic dataset for object class recognition (20 classes). | [The PASCAL Visual Object Classes (VOC) Challenge](https://link.springer.com/article/10.1007/s11263-009-0275-4) | `classification` `detection` `segmentation` | [Website](http://host.robots.ox.ac.uk/pascal/VOC/) |
| **CIFAR-10/100** | Tiny images (32x32) labeled in 10 or 100 classes. | [Learning Multiple Layers of Features from Tiny Images](https://www.cs.toronto.edu/~kriz/learning-features-2009-TR.pdf) | `classification` `low-resolution` `general` | [Website](https://www.cs.toronto.edu/~kriz/cifar.html) |
| **MNIST** | Handwritten digits database (0-9). | [Gradient-Based Learning Applied to Document Recognition](http://yann.lecun.com/exdb/publis/pdf/lecun-01a.pdf) | `classification` `digits` `grayscale` | [Website](http://yann.lecun.com/exdb/mnist/) |
| **Open Images** | ~9 million images annotated with image-level labels, bounding boxes, and masks. | [The Open Images Dataset V4: Unified Image Classification, Object Detection, and Visual Relationship Detection at Scale](https://arxiv.org/abs/1811.00982) | `detection` `segmentation` `multimodal` | [Website](https://storage.googleapis.com/openimages/web/index.html) |
| **Cityscapes** | Semantic urban scene understanding dataset (street scenes). | [The Cityscapes Dataset for Semantic Urban Scene Understanding](https://arxiv.org/abs/1604.01685) | `segmentation` `driving` `urban` | [Website](https://www.cityscapes-dataset.com/) |
| **ADE20K** | Scene parsing dataset with 150 object/stuff categories. | [Scene Parsing through ADE20K Dataset](https://arxiv.org/abs/1608.05442) | `segmentation` `scene-parsing` `indoor` `outdoor` | [Website](http://groups.csail.mit.edu/vision/datasets/ADE20K/) |
| **LOD (Low-light)** | Low-light Object Detection dataset for crafting detection in very low light. | [Crafting Object Detection in Very Low Light](https://arxiv.org/abs/2108.06648) | `detection` `low-light` `night` | [Website](https://github.com/ying-fu/LODDataset) |
| **KITTI** | Autonomous driving benchmark (stereo, flow, detection). | [Are we ready for Autonomous Driving? The KITTI Vision Benchmark Suite](http://www.cvlibs.net/publications/Geiger2012CVPR.pdf) | `driving` `stereo` `lidar` `3d` | [Website](http://www.cvlibs.net/datasets/kitti/) |
| **BDD100K** | Large-scale diverse driving video dataset. | [BDD100K: A Diverse Driving Dataset for Heterogeneous Multitask Learning](https://arxiv.org/abs/1805.04687) | `driving` `video` `segmentation` `detection` | [Website](https://bdd-data.berkeley.edu/) |
| **LFW** | Labeled Faces in the Wild for unconstrained face recognition. | [Labeled Faces in the Wild: A Database for Studying Face Recognition in Unconstrained Environments](http://vis-www.cs.umass.edu/lfw/lfw.pdf) | `face-recognition` `people` `wild` | [Website](http://vis-www.cs.umass.edu/lfw/) |
| **IMDB-WIKI** | Large dataset of face images with age and gender labels. | [DEX: Deep EXpectation of apparent age from a single image](https://data.vision.ee.ethz.ch/cvl/publications/papers/rothe-iccv15.pdf) | `face` `age` `gender` `classification` | [Website](https://data.vision.ee.ethz.ch/cvl/rrothe/imdb-wiki/) |
| **CelebA** | Large-scale face attributes dataset with >200K celebrity images. | [Deep Learning Face Attributes in the Wild](https://arxiv.org/abs/1411.7766) | `face` `attributes` `people` | [Website](http://mmlab.ie.cuhk.edu.hk/projects/CelebA.html) |
| **Fashion-MNIST** | Dataset of Zalando's article images (clothing) similar to MNIST. | [Fashion-MNIST: a Novel Image Dataset for Benchmarking Machine Learning Algorithms](https://arxiv.org/abs/1708.07747) | `classification` `fashion` `clothing` | [Website](https://github.com/zalandoresearch/fashion-mnist) |
| **LSUN** | Large-scale Scene Understanding challenge dataset (bedroom, kitchen, etc.). | [LSUN: Construction of a Large-scale Image Dataset using Deep Learning with Humans in the Loop](https://arxiv.org/abs/1506.03365) | `classification` `scene` `generation` | [Website](https://www.yf.io/p/lsun) |
| **Visual Genome** | Knowledge base connecting structured image concepts to language. | [Visual Genome: Connecting Language and Vision Using Crowdsourced Dense Image Annotations](https://arxiv.org/abs/1602.07332) | `vqa` `relationships` `captioning` | [Website](https://visualgenome.org/) |
| **MegaFace** | Million-scale face recognition benchmark. | [MegaFace: A Million Faces for Recognition at Scale](https://arxiv.org/abs/1512.00596) | `face-recognition` `large-scale` | [Website](http://megaface.cs.washington.edu/) |
| **YouTube-8M** | Large-scale video classification dataset with 8 million videos. | [YouTube-8M: A Large-Scale Video Classification Benchmark](https://arxiv.org/abs/1609.08675) | `classification` `video` `large-scale` | [Website](https://research.google.com/youtube8m/) |
| **Kinetics** | Large-scale high-quality dataset of video URLs for human action recognition. | [The Kinetics Human Action Video Dataset](https://arxiv.org/abs/1705.06950) | `action-recognition` `video` `human` | [Website](https://deepmind.com/research/open-source/kinetics) |
